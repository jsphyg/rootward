# The Weather Book

Twenty chapters about reading the sky, shown on the site as a plain reader at
https://jsphyg.github.io/rootward/weather-book/.

Start with `../../project/notes/weather-book.md`: status, where every file is, the style rules, how to
build, and what's left.

Build: `python3 build/build_book.py --book subjects/weather-book --out docs/weather-book`
(run from the repository root).
